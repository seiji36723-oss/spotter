# SPOTTER

チョコザップのマシンで組む、全身トレーニングの記録アプリです（非公式）。

- 行けた日に A→B→C の順でメニューをやる順番制
- 前回の重さ・回数から、今日の目標を自動で出す
- 部位ごとの週のセット数、体の図、伸びのグラフで記録を見る

## 使い方（iPhone）
1. Safari でアプリのURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の SPOTTER のアイコンから開く（全画面で開き、電波がなくても動きます）

記録はそれぞれのスマホの中だけに保存されます。機種変更のときは「設定 → 記録を書き出す」でコピーし、新しいスマホの「記録を読み込む」に貼り付けてください。

## ファイル
- `index.html` … アプリ本体（1ファイル）
- `manifest.webmanifest` … アプリの名前・アイコンの設定
- `sw.js` … オフラインで動くようにするしくみ
- `icons/` … アイコン画像

## Android アプリ
`main` に変更が入るたびに、GitHub が自動で Android アプリ（`SPOTTER.apk`）を作り、このリポジトリの「Releases」に置きます。
Android のスマホで `SPOTTER.apk` をダウンロードして開くと入れられます（「提供元不明のアプリ」を許可する画面が出たら許可）。

- `android/` … Android アプリのしくみ（`index.html` を全画面で表示するだけ）
- `setup/android.yml` … APK を自動で作る手順。GitHub の画面で `.github/workflows/android.yml` に移すと動き出します
